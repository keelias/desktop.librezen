# Security Policy

LibreZen is an experimental community project. Please do not report LibreZen vulnerabilities to Zen Browser or LibreWolf maintainers unless the issue is independently confirmed to affect their upstream projects.

## Reporting a Vulnerability

For a potential security vulnerability specific to LibreZen, use [GitHub's private security advisory reporting page](https://github.com/keelias/desktop.librezen/security/advisories/new). Do not open a public issue for an unpatched, exploitable vulnerability.

Include the affected commit or build, operating system, reproduction steps, and relevant logs with secrets and personal data removed. Avoid attaching browser profiles, cookies, authentication tokens, or browsing histories.

If the issue is clearly inherited from Mozilla Firefox, Zen Browser, or LibreWolf, please also follow that project's own reporting guidance. LibreZen is not an official release of any of those projects.
